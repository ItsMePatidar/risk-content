# 1.14 Credit Stress Testing

## Definition

Credit stress testing projects how a loan book's default and loss rates behave under adverse but plausible macroeconomic conditions. In retail lending the shocks that matter are labour-market and rate-related - a rise in unemployment, a fall in real income growth, a policy rate increase that raises floating-rate EMIs, or a fall in collateral values. The output is a projected path for delinquency, provisions, and capital, not a single number. Stress testing sits alongside scenario analysis for IFRS9 and feeds board-level risk appetite and capital planning under ICAAP.

## Why it matters

Retail portfolios look stable right up to the point where they do not. Because the parameters are estimated from recent data, a book that has only lived through benign conditions carries PD estimates that have never been tested against a downturn. Stress testing is the discipline that forces the question of what happens if unemployment rises 200 bps, and it produces a number that can be compared against capital. It is also the mechanism through which forward-looking information enters IFRS9 provisions, so the same scenario machinery serves both a regulatory purpose and an accounting one. Retail books have specific transmission channels that corporate stress tests miss entirely: EMI shock on floating-rate mortgages, the collateral-value channel on LAP and auto, and the sharp non-linearity of unsecured delinquency in response to employment shocks.

## Formula

Two approaches are used, usually together.

Structural (single-factor) approach - shocks the systematic risk factor directly, using the same Vasicek framework that underlies the IRB formula:

```
PD_stressed = N[ ( G(PD) - sqrt(R) x z ) / sqrt(1 - R) ]
```

where:
- `PD` = unstressed through-the-cycle probability of default, in %
- `R` = asset correlation for the retail sub-class, in %
- `z` = realisation of the systematic factor, in standard deviations; negative values are adverse
- `G[.]` and `N[.]` = inverse and cumulative standard normal functions

At z = -3.09 this reproduces the 99.9th percentile default rate embedded in the IRB capital formula, which makes it a useful internal consistency check.

Econometric (macro-linked) approach - regresses observed default rates on macro variables:

```
logit(DR_t) = a + b1 x dU_t + b2 x dR_t + b3 x dY_t + e_t
```

where:
- `DR_t` = observed portfolio default rate in period t, in %
- `dU_t` = change in the unemployment rate, in percentage points
- `dR_t` = change in the policy or lending rate, in percentage points
- `dY_t` = change in real income or GDP growth, in percentage points
- `a` = intercept, calibrated so the equation reproduces the current default rate at zero shocks
- `b1, b2, b3` = sensitivities, estimated on historical data or benchmarked where internal history is short

The logit form matters. Because the relationship is convex in default rate space, a symmetric macro shock produces an asymmetric loss response - the upside case improves losses less than the downside case worsens them.

The EMI-shock channel is retail-specific and is modelled separately:

```
FOIR_stressed = (Existing EMIs + EMI at stressed rate) / NMI
```

## Worked Example

Example: stressing the personal loan portfolio - ₹1,840 crore, PD 4.10%, LGD 72%, R = 6.096% from 1.10.

Structural approach, at a two-standard-deviation adverse systematic shock (z = -2.0):

```
G(0.0410) = -1.7392
sqrt(R) = 0.24691,  sqrt(1-R) = 0.96883

PD_stressed = N[ ( -1.7392 - 0.24691 x (-2.0) ) / 0.96883 ]
            = N[ ( -1.7392 + 0.49382 ) / 0.96883 ]
            = N[ -1.28545 ] = 9.93%
```

PD more than doubles from a two-sigma shock. That convexity is the single most important property of the exercise.

Econometric approach, with a base-case logit calibrated to the current 4.10% default rate:

```
a = ln(0.0410 / 0.9590) = -3.1520
Scenario: unemployment +2.1 pp, lending rate +150 bps
Sensitivities: b1 = 0.185 per pp, b2 = 0.110 per pp

logit(DR) = -3.1520 + (0.185 x 2.1) + (0.110 x 1.5)
          = -3.1520 + 0.3885 + 0.1650 = -2.5985
DR_stressed = 1 / (1 + e^2.5985) = 6.93%
```

The two methods bracket the answer at 6.93% and 9.93%, which is the normal outcome - the structural approach is calibrated to a tail percentile, the econometric one to a specific named scenario.

Loss and capital impact, using the econometric result and a downturn LGD of 79% (up from 72%, reflecting weaker collections and settlement realisation in a downturn):

```
Base EL      = 4.10% x 72% = 2.95%  -> ₹54.3 cr
Stressed EL  = 6.93% x 79% = 5.47%  -> ₹100.6 cr
Incremental annual credit cost      = ₹46.3 cr
```

Against the base-case RAROA of 4.37% from 1.1, an EL increase of 252 bps turns a 4.37% return into 1.85%. Post-tax, roughly ₹34.7 crore of the incremental loss depletes CET1 directly, while the standardized risk weight of 125% on a ₹1,840 crore book leaves RWA unchanged - so the capital ratio falls with no offsetting relief.

EMI-shock channel on a floating-rate home loan. Principal ₹42,00,000, 20-year term, 8.60% floating.

```
EMI at 8.60%  = ₹36,715
EMI at 10.10% = ₹40,808
Increase = ₹4,093, or 11.15%
```

For a borrower originated at a 42.0% FOIR, this pushes FOIR to 46.7% before any change in income. In practice Indian lenders usually absorb rate increases by extending tenor rather than raising the EMI, which suppresses the visible stress entirely - and pushes the borrower's loan past their expected retirement age. The stress test should model both responses, because tenor extension converts an immediate affordability shock into a long-dated one that never appears in FOIR monitoring.

## Common Pitfalls / Misconceptions

- Stressing PD and holding LGD constant. PD and LGD are positively correlated. A stress test that shocks only PD understates loss by 15-25% in secured portfolios, where the collateral channel is exactly what is breaking.
- Calibrating sensitivities on a benign sample. If internal default history covers only expansion years, the estimated `b1` on unemployment will be too small. Benchmarking against a longer external series, or against a peer jurisdiction's downturn, is usually necessary.
- Assuming linearity. A 200 bps unemployment shock does not produce twice the loss of a 100 bps shock. The logit and Vasicek forms both build in convexity, and linear extrapolation from a mild scenario materially understates the severe one.
- Treating the 99.9% IRB percentile as a stress scenario. It is a capital calibration, not a forecast. Supervisory stress scenarios typically sit around one-in-twenty-five to one-in-fifty year severity.
- Ignoring behavioural and portfolio responses. In a real downturn the lender tightens cutoffs, cuts unused limits, and shifts collections capacity. A static-balance-sheet stress test that ignores management action overstates loss; one that assumes perfect management action understates it. Both versions should be run.
- Overlooking the tenor-extension channel on floating-rate retail. It hides affordability stress from every conventional monitoring metric.
